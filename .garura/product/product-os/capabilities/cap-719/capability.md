# Capability: View plans

## Directional intent
show plans from the plan files alone — no tracker reads, no inference.

## Agent intent (ICE)
- Goal: A person or agent sees where every plan stands without reading issues or work folders.
- Limit: Read only: it never changes a plan or the tracker.
- Fails if: showing a plan needs a tracker read or a model call, or the same files print differently twice.
- Checked by: the view of the two plans filed on 2026-10-21 matches the trees in their plan files.
