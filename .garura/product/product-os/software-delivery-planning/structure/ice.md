## Intent
- Goal: Everything Garura keeps has one written place: each kind of part, each tool, the memory source and the one settings file in Garura's source; each installed part, the shared files, the tools, the memory guide, the settings file and the install record at a fixed place in the project; everything in `.garura/` on its written list, with a check that names what is off it; and every run's records in the folder of the issue that made them, with only repository paths, so parts and people find each thing by a known path, an installed part never needs the source, and nothing a run did is lost in a global file.
- Limit: An installed part reads, runs and names only installed files, never a path under `core/components/` or `core/tools/`.
- Limit: The installed copy is never edited to make a change; a change is made in the source and reaches a project through an install.
- Limit: Nothing a run writes goes into a global file unless a written rule first gives that place its structure.
- Limit: What each kind of part is, what each setting means, what enters each tier of memory, each coding tool's own folders, laying the parts and the checks of the standard stay with their owners.
- Fails if: An installed part names a path in Garura's source, or a part, a shared file or a tool is laid where the written layout does not put it.
- Fails if: `.garura/` holds a folder or file its written list does not name, and nothing names it.
- Fails if: A run's record sits outside its issue's folder with no written rule for that place, or a committed run record holds a home-folder path.

## Context
- Read: Gather it from the memory layer. Look first at the project's existing memory and its existing implementation, then Garura memory, then Phoenix memory. If none of them answers, research it and raise a memory update for a person to approve. For this part, look for: the source folders and the settings that name them; the install's adapters and where each lays a part; the install record; the written layouts of `.garura/` in the decision records, the docs and the glossary; a listing of `.garura/` as it is and what git ignores in it; where each play writes its run records and the paths written in them; and the approved pages that hand where each part lives to this capability.
- Never read: any memory file by its path, any ICE page, and any file under a plan's evals folder.
- Persona: the developer, a person or an AI agent who builds the code, who adds a part or a tool and must know where it goes; and the technical lead, who keeps the layout and reads where each run's records are.
- Scope: In: where each kind of part, tool, the memory source and the settings file live in the source; where each installed part lands in a project; the written list of `.garura/` and its check; and each run's records in its issue's folder, with only repository paths. Out: what each kind of part is and the checks of the standard, what each setting means, what enters each tier of memory and the machine-wide copy of all memory, laying the parts and each coding tool's own folders, the skip records and what is owed, the scan of a push, which records a review reads, what the product model holds, and keeping a plan's evals from its builders.

## Expectation
- Scenario: In a harness repository like Garura's, a developer adds a tool: it goes in the source's tools folder, the install lays it in the project's tools folder, and the play that runs it names the installed path. In a clinic's booking app with Garura installed, a decision recorded by hand writes its records in the folder of the issue it decides, with every path from the repository's root, and the check of `.garura/` finds nothing off its list.
- Done means: Someone other than the one who laid it out reads the written layouts, lists the source, an installed project and its `.garura/` folder, and searches the committed run records, and finds each part where the layout puts it, no installed part naming a source path, nothing in `.garura/` off the list, and every run's records in its issue's folder with no home-folder path.
