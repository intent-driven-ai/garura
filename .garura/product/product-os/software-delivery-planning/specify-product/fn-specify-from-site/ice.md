## Intent
- Goal: Every view a deployed site offers is captured, up to two clicks deep.
- Limit: It never changes data or follows a link out of the prototype.
- Fails if: A view it couldn't reach isn't recorded with why.

## Context
- Read: Gather it from the memory layer. Look first at the project's existing memory and its existing implementation, then Garura memory, then Phoenix memory. If none of them answers, research it and raise a memory update for a person to approve. For this part, look for: the site.
- Persona: the product owner giving a link to a deployed site.
- Scope: In: every view up to two clicks deep, each saved as a picture and its text. Out: views deeper than two clicks, any step that changes data, starting a local app, and saying what the site shows.

## Expectation
- Scenario: A first screen with three controls that each open a different view gives four pictures and four texts, and the record reads four kept.
- Done means: Each view is saved, or named as unreached.
