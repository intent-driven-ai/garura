## Intent
- Goal: A document is kept exactly as given.
- Limit: It's never changed or summarised in place.
- Fails if: The copy differs from the original.

## Context
- Read: Gather it from the memory layer. Look first at the project's existing memory and its existing implementation, then Garura memory, then Phoenix memory. If none of them answers, research it and raise a memory update for a person to approve. For this part, look for: the document.
- Persona: the product owner giving a document, such as a brief.
- Scope: In: an exact copy of any file that isn't a web page. Out: a web-page file, saying what the document shows, and reading the moments in a video.

## Expectation
- Scenario: A brief in a file is captured, and the copy's fingerprint equals one worked out from the original.
- Done means: The saved copy matches by its fingerprint.
