## Intent
- Goal: Once the built work runs in the testing environment, a part that is not the builder opens on each declared surface each screen the screen design shows, at each screen size the surface names, keeps a picture of it with the text and the controls it shows, or for a command line or a coding agent's play runs it in a test project with set answers and keeps what it printed and asked, checks what needs no judgment, and records for each part the result with the surface, the screen, the size and the tool, so the person who walks has the evidence and the product owner knows which parts a tool found met.
- Limit: Nothing is tested outside the testing environment: not production, not a builder's own machine, and no system the testing environment does not hold; the test uses only the environment's made-up data and test accounts, and writes no secret's value.
- Limit: What to open, at which sizes, what a tool checks and with which tool come only from the surface's declaration, the screen design and the project's settings, read from memory first; a screen, a size or a surface no known tool can open, a tool that could not run, and a part a person must judge are never passed by a tool.
- Limit: Only what this yardstick names is kept, each result with what was checked and where, so a second run can repeat it; the builder never sees the pictures or the results.
- Fails if: A test reached production, a builder's own machine or a system the testing environment does not hold.
- Fails if: A screen or a size that no tool opened, or a part a person must judge, is counted as passed after a tool's clean run.
- Fails if: A result is recorded without its surface, screen, size and tool, or a picture or a result reached a part that builds the work.

## Context
- Read: Gather it from the memory layer. Look first at the project's existing memory and its existing implementation, then Garura memory, then Phoenix memory. If none of them answers, research it and raise a memory update for a person to approve. For this part, look for: the declared surfaces with who opens each, each one's properties, such as the screen sizes it serves, and its guidelines, the screen design in force with the screen design setting, how each surface is reached in the testing environment, the tools the project's settings and code already name, the testing environment's declaration with its data and test accounts, and where the deployment design keeps the testing environment's secrets and which tests it places there.
- Never read: the value of any secret other than the testing environment's own, which a test takes at run time and never writes down; anything in production, such as its data or its traffic; and any ICE page.
- Persona: the product owner, who wants to know which screens open at every size each surface names, and the person who walks, who judges from the pictures.
- Scope: In: opening each screen at each size each surface names, or running a command or a play in a test project, in the testing environment, with what was checked and where recorded. Out: judging the layout, the design system and the match with the screen design, the verdict and the handoff plans, a story's own lines, what accessibility, security and performance name, building the environment, and fixing.

## Expectation
- Scenario: A clinic's booking page runs in the testing environment. Its browser surface names a phone and a desktop screen size, and its screen design is a prototype built with the clinic's design system. The tools walk the booking with the same steps on the build and on the prototype, keep a picture of each step at both sizes, and record that every screen opens at both sizes except the confirmation screen, which does not open at the phone size, recorded as a fail with the screen, the size and the tool. Whether the screens match the prototype is left for the walk, not passed.
- Done means: Someone other than the one who ran the tools runs them again on the same built work, and finds the same screens opened at the same sizes, the same pass or fail for each part, every result with what was checked and where, each part not tested named with its reason, no part a person must judge counted as passed, and every check inside the testing environment.
