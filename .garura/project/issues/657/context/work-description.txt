Story #657 under Feature #653 (feature plan item 4): the memory tool from the contract (#655), with a folder engine. It finds files, searches their text and reads exact lines the way Claude Code does. It looks in the current issue's short-term memory, then Garura memory (the project's .garura/), then Phoenix memory, and stops at the first tier that answers. It pulls a piece into Garura memory when it finds it in Phoenix memory (reusing pull.py from #656), and writes approved updates to their tier. Every result carries tier, file, lines and fingerprint. Finish test (Kapil, 2026-10-18): in an empty project a simulated login story finds nothing in short-term or Garura memory, finds it in Phoenix memory and pulls it; a re-run reads it from Garura memory; a change-password story gets part from Garura memory and the rest from Phoenix memory; with project memory removed, the tool goes to Phoenix memory or raises a memory update that needs approval. Decided in ADR 035, amended by ADR 036.
