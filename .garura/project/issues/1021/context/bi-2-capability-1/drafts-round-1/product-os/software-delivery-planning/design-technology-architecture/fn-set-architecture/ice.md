Thin: proposed from the person's words; deepen with `/discover-capabilities`.

## Intent
- Goal: The shape of the whole system is set once for the project: its style, each main part with its one job, and each seam with what crosses it, each a position with its reasons, its source and the person who confirmed it.
- Limit: Each proposal names its source, the project's code first and then memory, and a choice that nothing backs stays open, with no default.
- Limit: A part is named by its job, never by the product that runs it.
- Limit: Only a person confirms a position, and no work waits for one.
- Fails if: A position is written with no source, or with no person's confirmation.
- Fails if: Two main parts hold the same job, or a seam does not say what crosses it.
- Fails if: Work stops because an architecture position is missing.

## Context
- Read: Gather it from the memory layer. Look first at the project's existing memory and its existing implementation, then Garura memory, then Phoenix memory. If none of them answers, research it and raise a memory update for a person to approve. For this part, look for: the project's code, its settings and how it is deployed, the product profile with its shape and quality levels, the architecture learnings in memory with the conditions each fits and the style that comes after it, and the positions already set.
- Persona: the architect, who confirms each architecture position.
- Scope: In: proposing and setting the style, the main parts and the seams of the whole system. Out: the products and versions that run each part, changing a confirmed position, each slice's own parts and seams, the platform the product runs on and its environments, and the product profile.

## Expectation
- Scenario: A new internal tool for a small team is proposed one deployable unit with firm module borders, with the memory learning that fits it, and the architect confirms it.
- Done means: An agent that did not set the positions reads them and names the style, each main part with its job and each seam with what crosses it, and a person other than the one who set them agrees with what the agent named.
