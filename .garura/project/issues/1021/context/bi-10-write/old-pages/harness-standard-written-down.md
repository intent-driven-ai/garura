# Capability: The harness standard, written down

## Directional intent
one published standard — naming rules, the principles behind how a harness is built, and the practices that follow from them, in plain words a client can read.

## Agent intent (ICE)
- Goal: Anyone can name and build a harness part the Garura way from the standard alone.
- Limit: Says what and why; how each part is built stays in its own docs.
- Fails if: a rule exists only in code or in a person's head.
- Checked by: a reader with only the standard names five new parts and the linter passes all five.
