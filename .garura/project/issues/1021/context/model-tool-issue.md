## What this is

A tool that knows how to create and edit the product model. It is recorded now and built later: it is not approved to build yet.

## Why

The product owner, 2026-11-05: "we need a tool that knows how to create and edit the product model. we will build it later."

Today a language model composes the model's pages, and they drift from the ontology. The latest case came up under #1021 (the reorganisation of the business intents). A capability and twelve features were written with their ICE as a section of the page, in five flat lines. The ontology says an ICE has its own page and its own entry in the model's index, with three parts: Intent, Context and Expectation. The page template and the page skill still describe the older shape, and nothing stopped it.

## Where it belongs

- Business intent: `garura-intents#11` (Product model).
- Capability: Manage the model.
- Product model part owed: one feature under Manage the model. It is added when that capability and all of its features are reviewed together, so it has no model page yet.
