# [BUG] The skill author-product-ontology is user-invocable

Skills are never run by a person. Plays run skills. The skill `author-product-ontology` breaks this rule.

## What happens

- `core/components/skills/author-product-ontology/SKILL.md` sets `user-invocable: true`, so the harness install shows it as the command `/author-product-ontology`.
- `docs/components/skills.md` writes this down as a "meta-utility skill" exception.
- On 2026-10-22 the coding agent ran it directly for #758, outside any play. The product owner stopped it: "you are supposed to start with plays only and plays are the ones that call skills".

## Expected

- The skill is `user-invocable: false`, like every other skill.
- The meta-utility exception is removed from `docs/components/skills.md` and the skill's own text.
- The play from #777 is the only way to run it.

## Done when

- No skill in `core/components/skills/` has `user-invocable: true`.
- The component linter fails any skill that sets `user-invocable: true`.
- A harness install shows no `/author-product-ontology` command.
