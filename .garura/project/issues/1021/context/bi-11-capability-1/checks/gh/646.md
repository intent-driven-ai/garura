# Agents build only from approved pieces

## What this delivers
ADR 033 §3–§4: the governance rule. An agent takes an ICE only when the ICE itself, the capability or functionality it sits on, and the business intent it is built from are all approved. Approval follows links.

## Done when
- The workable check (`core/components/plays/intent/scripts/check_ice_workable.py` and its copy in `core/components/plays/play-creator/references/`) reads the approval state and follows the links.
- An agent refuses an ICE whose business intent is not approved, and one whose capability changed since it was approved.
- Every play that works on ICE uses the check.

## Not in this story
- Adding the approval state to the model — the story before this one.
- Blocking any write: a rule stops work, never a write.
