## Intent
- Goal: People and agents share one written map of what a product is made of, its kinds, what each holds, how they link, its rules and a real example of each, which changes only through one play, one need at a time, with the product owner's typed yes at three points, is read valid by a script, reaches every project at the same version through the memory tool, and is followed by every part that reads it; and each change to it runs the model's checks before and after, as findings, so a person and an agent use the same words for the same things and the model moves with the map.
- Limit: The map changes only through /edit-ontology; no person and no other play edits it by hand or runs its skill.
- Limit: A change touches only the kinds its need names, raises the version by one, and adds one log line.
- Limit: A rule of the map never stops a write, and a finding of the model's checks never stops the work.
- Limit: Only a person confirms or drops a business intent.
- Fails if: The map changes with no product owner's typed yes on record at each of the three points, or a change lands while the ontology check fails.
- Fails if: A project reads a version of the map other than the one in Garura's source, or a template, the index's schema, the structure check or the glossary describes a shape the map replaced.
- Fails if: A change to the map stops someone's work, or lands without the model's checks run before and after it.

## Context
- Read: Gather it from the memory layer. Look first at the project's existing memory and its existing implementation, then Garura memory, then Phoenix memory. If none of them answers, research it and raise a memory update for a person to approve. For this part, look for: the ontology with its questions, kinds and log, the map's play with its checks and its records of each yes, the skill it runs, the settings' place of the ontology in memory, the page templates, the index's schema, the structure check, the glossary, the model's checks and their last reports, the product owner's recorded answers on the map, and the open issues named on this capability's page.
- Never read: any memory file by its path, and any ICE page.
- Persona: the product owner, who agrees each change to the map; the technical lead and the developer, a person or an AI agent who builds the code, whose plays and agents write and check the model by the map.
- Scope: In: the map, changing it through its play, bringing it to every project, keeping the parts that read it in step; and, not built yet, the model's checks before and after each change, a recorded version of the map a model is built to, a team's own extension with its plays, the product profile and the product decision as kinds, and the approval state each kind carries. Out: the model's parts and its checks, moving a model to a new version's shape, keeping Phoenix memory in step, the ICE of plays and loops, building plays, the discovery plays, the way past each gate, writing approval in the review, and landing the change.

## Expectation
- Scenario: In a clinic's booking app, the product owner asks for a property on the Feature kind that says which reminder a patient gets. The map's play stops at the questions, the kinds, and the links and rules, and writes nothing as agreed before each typed yes; the check reads the map valid; the version goes up by one with one log line; before it lands, the model's checks show that 14 feature pages lack the new property, recorded as owed, and the work of the day goes on. In a bank's payments service, the agents that write and check its model read the same version of the map through the memory tool as Garura's source holds, and the page template they write from has the ICE on its own page.
- Done means: Someone other than the one who changed the map reads the ontology, its log, the play's records of each yes, the check reports and the model's check reports from before and after, and finds three typed yeses recorded before the map was written, only the kinds the need touched changed, the version up by one with one log line, the check valid, the findings recorded as owed with no work stopped, and the same version of the map in Phoenix memory as in Garura's source.
