# Waiting on other work, and pulling the next item

- GitHub issues can be marked as blocked by, or blocking, other issues, in the web, with gh (--blocked-by and --blocking take issue numbers or URLs; the docs' example names an issue of another repository) and through the REST API. A blocked issue shows a Blocked icon in the issue list and on project boards. Whether it may point to another organization is not stated. https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/creating-issue-dependencies
- The Kanban Guide: start work on an item (pull or select it) only when there is a clear signal of capacity; control the number of items in progress explicitly; define when an item starts and finishes. It sets no order for which item is pulled first. https://kanbanguides.org/english/
