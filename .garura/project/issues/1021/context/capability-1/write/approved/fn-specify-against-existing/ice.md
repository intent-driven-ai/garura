## Intent
- Goal: What's given is sorted against what exists: a new intent, an enhancement, a new feature under one, or a clash.
- Limit: A person decides any clash, and nothing existing changes on its own.
- Fails if: Something that exists gets written as new.

## Context
- Read: Gather it from the memory layer. Look first at the project's existing memory and its existing implementation, then Garura memory, then Phoenix memory. If none of them answers, research it and raise a memory update for a person to approve. For this part, look for: the model, the project, its code.

## Expectation
- Done means: Give it something overlapping an existing intent, and it says so.
