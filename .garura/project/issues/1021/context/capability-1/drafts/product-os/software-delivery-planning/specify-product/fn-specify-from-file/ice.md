## Intent
- Goal: A file is kept, and every view it offers is captured.
- Limit: The copy never changes.
- Fails if: A view it could reach isn't kept.

## Context
- Read: Gather it from the memory layer. Look first at the project's existing memory and its existing implementation, then Garura memory, then Phoenix memory. If none of them answers, research it and raise a memory update for a person to approve. For this part, look for: the file.
- Persona: the product owner giving a prototype as one file.
- Scope: In: one web-page file, its exact copy, and a picture and the text of each view. Out: a project folder, a deployed site, and walking the journeys.

## Expectation
- Scenario: A web-page file with three controls that each open a view gives the exact copy, four pictures and four texts.
- Done means: Each view is saved with its picture and text.
