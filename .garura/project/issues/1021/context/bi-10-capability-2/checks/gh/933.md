A team building a Phoenix harness has an architecture memory to build and review against
Serves business intent #734 (Garura publishes a standard for building agentic harnesses). Filed with no parent; its model part (this feature under its capability, with its ICE) is owed. Comes before #934, the three-layer severity rules, which test against it.

## Why

There is no memory of how a harness built on the Phoenix architecture is put together. An agent that reviews a change, or a team that wants to build its own harness, has nothing to read that says which part may do what. So a break of a decided pattern — for example a subagent that reads memory by its path instead of through the memory tool (#928, #925, #926) — is found by chance, and its severity is argued case by case (the product owner, 2026-10-28: "I don't think that memory exists. You will have to create the memory, and that is your architectural pattern").

## What a person can do

A team building a harness on the Phoenix architecture reads, in Phoenix memory, how such a harness is built, without taking the whole of Garura, and a review tests a change against it.

## Scope

New pages in Phoenix memory, under `standards/architecture/phoenix/` (the product owner: the Phoenix architecture goes under the architecture standards, so a team can take the architecture without the whole core):

- the parts and what each may do: play, loop, subagent (agent), skill, script and tool;
- what calls what, and what each hands the next (the contracts);
- memory: the tiers, the memory tool, and who may call it;
- what a run leaves behind: run records, evidence, the product model;
- the folders: the source, the installed copy, short-term memory;
- the decided patterns, each with the decision record behind it and whether it is load-bearing (breaking it sets the severity floor in #934).

Not in scope: Garura's own plays and their names; the severity rules (#934).

## Done when

The pages are in Phoenix memory, each pattern names its decision record, and a review agent can find them through the memory tool and cite them.
