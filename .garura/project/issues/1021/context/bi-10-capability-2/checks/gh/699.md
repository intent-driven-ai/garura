feat: loop builders and the loop linter check the loop principles
Kind: Story — a slice of the loops feature (#594), after #698.

What: make `/loop-creator`, `/loop-editor` and the loop linter (`lint_loop.py`) build and check every loop against the loop principles written in `docs/components/loops.md` ("The loop principles"). Today they meet some principles and miss others:
1. **A goal you can check.** Every loop has done checks and a round limit, but nothing checks that the goal itself is measurable ("make checkout faster" would pass). Add a check on the goal's stop condition.
2. **What starts the loop.** The builders never ask whether a person, a schedule or a hook starts it. Add a "Trigger" part to the loop's ICE and the run block.
3. **What the loop sees.** The source is read once and plays return short results, but no part of the ICE says what context each play gets, or how context is trimmed across rounds. Add a context part.
4. **A record across rounds.** Each round leaves files, but no single record tells the next round what was tried and whether it worked. Add a round log the shared run writes and reads.
5. **A person who reads the output.** The brief accepts one "yes" for every proposal. Decide how a loop guards against rubber-stamping (cognitive surrender).
The checker (a second agent on another model) and "act, check, adjust each round" are already met.

Why: the product owner, 2026-10-21: the loop principles from IBM's "What Is Loop Engineering?" (https://youtu.be/DQBqh6gcx7U) are the rules loops are built to, and "those documents are critical to how we build these". The Slice, Execute, Ship and Learn loops (#608–#611) should be built with them.

How: the decision goes through `/adr` first (the principles become binding). Builder changes are direct edits (`/loop-creator` and `/loop-editor` are hand-written); the Discovery loop changes through `/loop-editor`.

Done when:
- [ ] an accepted ADR makes the loop principles binding;
- [ ] `/loop-creator` asks for every principle's part, and `lint_loop.py` fails a loop that misses one;
- [ ] the Discovery loop passes the new checks;
- [ ] `docs/components/loops.md` shows every principle as met.
