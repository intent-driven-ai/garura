#860 (P1 bug): installed skills, agents, plays and loops read Garura's source tree (core/components, core/tools) at run time, so they break after an install into a project that has no core/ folder. Rule (the product owner, 2026-10-25): at run time a part never touches core/components or core/tools — that is precompiled code; it reads the installed copy (memory through the memory tool, tools from .garura/core/tools, shared files from the installed _shared folder). With it, the review-rules part (Q2-1 of the PR #858 review): a project says which kinds of review rule apply to it, so Garura's own reviews skip the database, permission and front-end rows.
