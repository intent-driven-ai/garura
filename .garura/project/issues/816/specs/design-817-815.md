# Design — #817 (grilling tier) and #815 (old-name check naming), grouped with #816

## #817 — the grilling tier setting

Blast radius: the config source, one new script and its test in the /shape-slice play. No play text changes (the play reads the tier in #795).

File changes:
1. `core/config.yaml` — a new section:
   ```yaml
   # shape-slice play configuration
   # grill-tier — how many questions /shape-slice may ask: xs 5, s 12, m 25, l 45, xl 70.
   #   The questions only the person can answer are always asked, and count first.
   shape-slice:
     grill-tier: m
   ```
2. `core/components/plays/shape-slice/scripts/grill_budget.py` — new. Two commands:
   - `tier --config <path>`: prints `{tier, budget}`. Absent setting → `m`, 25. Unknown value → exit 2 with the allowed values.
   - `split --questions <json> --budget <n>`: the questions carry `blocking: true|false`. Every blocking question is asked. The rest are asked in their given order until the budget is used. Each one not asked becomes an assumption. Prints `{asked, assumptions, over_budget}`. `over_budget` is true when the blocking questions alone are more than the budget (they are still asked).
3. `core/components/plays/shape-slice/scripts/test_grill_budget.py` — new tests.

Tests: each of the five tiers gives its budget; absent → m; unknown → exit 2; split keeps every blocking question; split never asks more than the budget when the blocking ones fit; each question not asked is in assumptions; blocking over budget → all asked and over_budget true.
