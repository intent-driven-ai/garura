Story #660 under Feature #653 (feature plan item 7): every Garura install carries the memory system. Installing Garura into a project installs the memory tool and a short memory guide every agent reads — the three tiers (Phoenix memory, Garura memory, short-term memory), what the tool does, and how to find memory, go up a tier, update it, name a source (a decision's trace, ADR 037) and raise a memory update. The guide says what ADR 036 set: short-term memory is the current issue only; a researched answer is used only after a person approves it and lands in the issue's short-term memory; promotion to Garura or Phoenix memory happens outside the work. The install checks the tool runs and reaches each tier, and fails with the tier named if it does not. Works for Claude Code and Codex (install-garura adapters). Decided in ADR 035 §8; amended by ADR 036 and ADR 037.
